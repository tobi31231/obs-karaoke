# Third-Party Notices

The Windows release bundles third-party runtimes, libraries, and model data.
Full license texts and upstream notices are included in the installed `licenses` directory.

Major bundled components:

- Microsoft .NET Runtime 8
- Microsoft Edge WebView2 SDK and Runtime
- Node.js
- Python
- faster-whisper
- CTranslate2
- OpenAI Whisper-compatible Turbo model
- SudachiPy and SudachiDict-core
- NVIDIA cuBLAS and cuDNN runtime components

The Python directory also contains license metadata supplied by each installed package.
NVIDIA components remain subject to NVIDIA's redistribution terms.

Before a public release, review the final binary inventory against the installed `licenses` directory.
